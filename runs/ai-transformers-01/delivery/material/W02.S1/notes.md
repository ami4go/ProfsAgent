## 3. From Soft Lookup to Self-Attention

- Recap from Week 1: Attention acts as a soft key-value lookup mechanism
- Input sequence embeddings X in R^(N x d_model) represent sequence tokens
- Self-attention enables tokens within the same sequence to attend to each other
- Queries (Q), Keys (K), and Values (V) are generated from the same input sequence

Input Embeddings X → Linear Transformations → Queries Q, Keys K, Values V → Scaled Dot-Product Attention → Contextual Outputs Z

*Overview of Self-Attention Dataflow*

**Notes** (5 min · outcomes CO2.LO1 · sources [C1] [C3] [C5]): In Week 1, we introduced attention conceptually as a database-like soft lookup where a query matches keys to compute a weighted sum of values. In self-attention, the queries, keys, and values all originate from the exact same sequence of input vectors. Every token in the sequence gets to look at every other token, producing a contextual representation that captures dependencies regardless of distance.

## 4. Linear Projections for Queries, Keys, and Values

- Project input representations X using three learnable weight matrices
- W^Q in R^(d_model x d_k), W^K in R^(d_model x d_k), W^V in R^(d_model x d_v)
- Query matrix Q = X W^Q with dimensions N x d_k
- Key matrix K = X W^K with dimensions N x d_k
- Value matrix V = X W^V with dimensions N x d_v

**Notes** (5 min · outcomes CO2.LO1 · sources [C3] [C4] [C5]): To allow the model to learn different interaction spaces, input embeddings X are projected into separate Query, Key, and Value spaces. We multiply X by three independent, learnable weight matrices W^Q, W^K, and W^V. The Query and Key projections share the dimension d_k because we must take dot products between them. The Value projection dimension d_v can differ, though in practice it often equals d_k.

## 5. The Scaled Dot-Product Attention Formulation

- Compute dot product similarity between queries and keys: Q K^T
- Scale the raw dot product scores by 1 / sqrt(d_k)
- Apply row-wise softmax to convert similarity scores into probabilities
- Multiply softmax probabilities by values V to get context matrix Z
- Equation: Attention(Q, K, V) = softmax(Q K^T / sqrt(d_k)) V

MatMul (Q, K^T) → Scale (1 / sqrt(d_k)) → Softmax (Row-wise) → MatMul (Weights, V)

*Scaled Dot-Product Attention Pipeline*

**Notes** (6 min · outcomes CO2.LO1 · sources [C3] [C4]): This fundamental formula forms the heart of the Transformer architecture. We matrix-multiply Q by K transpose to get an N-by-N matrix of similarity scores. We divide these scores by the square root of d_k, pass each row through softmax to get normalized attention weights summing to 1, and finally compute a weighted sum over the Value vectors.

## 6. Why Scale by the Square Root of Key Dimension?

- High-dimensional vectors produce large dot products under independent components
- If Q_i and K_i are independent zero-mean unit-variance random variables, Var(Q . K) = d_k
- Large magnitude logits push the softmax function into regions with tiny gradients
- Scaling by 1 / sqrt(d_k) controls the variance back to 1.0
- Prevents vanishing gradients during backward propagation

**Notes** (6 min · outcomes CO2.LO1 · sources [C2] [C3]): Why do we scale by the square root of d_k instead of using unscaled dot products? As the key dimension d_k grows large, dot product magnitudes grow proportionally to d_k, making their variance equal to d_k under standard initialization. Large dot product values push the softmax function into regions where output gradients are extremely small, leading to vanishing gradients. Dividing by sqrt(d_k) stabilizes training.

## 7. Matrix Form and Dimension Tracking

- Input sequence matrix X has shape (N, d_model) where N is sequence length
- Q and K have shape (N, d_k); Transposed K^T has shape (d_k, N)
- Matrix product Q K^T has shape (N, N) representing all pair-wise attention scores
- Softmax(Q K^T / sqrt(d_k)) preserves (N, N) matrix dimensions
- Multiplying by V with shape (N, d_v) yields output Z of shape (N, d_v)

| Matrix / Tensor | Mathematical Expression | Shape |
|---|---|---|
| Queries (Q) | X * W^Q | (N, d_k) |
| Keys Transposed (K^T) | (X * W^K)^T | (d_k, N) |
| Raw Scores (Q K^T) | Q * K^T | (N, N) |
| Values (V) | X * W^V | (N, d_v) |
| Output (Z) | Softmax(Q K^T / sqrt(d_k)) * V | (N, d_v) |

*Tensor Dimensions in Scaled Dot-Product Attention*

**Notes** (6 min · outcomes CO2.LO1 · sources [C3] [C4]): Tracking tensor dimensions is critical for understanding and implementing self-attention in code. Notice how sequence length N dictates the inner dimensions of the score matrix (N x N), while key dimension d_k is contracted away during matrix multiplication. The final output has sequence length N and dimension d_v, matching the input length while enriching feature representations.

## 8. Worked Example: Unmasked Scaled Dot-Product Step-by-Step (Worked problem)

- Let sequence length N = 2, key dimension d_k = 4, so sqrt(d_k) = 2.0
- Queries Q: [[1, 0, 1, 0], [0, 2, 0, 2]]; Keys K: [[1, 0, 1, 0], [0, 1, 0, 1]]
- Dot product matrix Q K^T = [[2, 0], [0, 4]]
- Scaled scores matrix (Q K^T / 2.0) = [[1.0, 0.0], [0.0, 2.0]]
- Row 1 Softmax: [e^1 / (e^1 + e^0), e^0 / (e^1 + e^0)] = [0.731, 0.269]
- Row 2 Softmax: [e^0 / (e^0 + e^2), e^2 / (e^0 + e^2)] = [0.119, 0.881]

| Step | Formula / Tensor | Resulting Matrix |
|---|---|---|
| 1. Raw Dot Product | Q K^T | [[2.0, 0.0], [0.0, 4.0]] |
| 2. Scaled Scores | Q K^T / sqrt(4) | [[1.0, 0.0], [0.0, 2.0]] |
| 3. Attention Weights | Softmax(Scaled Scores) | [[0.731, 0.269], [0.119, 0.881]] |
| 4. Weighted Values | Attention Weights * V | Z in R^(2 x d_v) |

*Unmasked Worked Example Calculations*

**Notes** (7 min · outcomes CO2.LO1 · sources [C2] [C4]): Let's walk through a numerical calculation step by step. With key dimension d_k = 4, our scaling factor sqrt(d_k) is 2. Matrix multiplying Q by K^T yields raw scores [[2, 0], [0, 4]]. Scaling by 2 gives [[1.0, 0.0], [0.0, 2.0]]. Applying row-wise softmax converts row 1 [1.0, 0.0] to [0.731, 0.269] and row 2 [0.0, 2.0] to [0.119, 0.881].

## 10. The Purpose of Causal Masking in Decoder Layers

- Autoregressive language models predict token i using only preceding tokens 1 to i - 1
- Standard self-attention allows all tokens to attend to all other tokens bidirectionally
- Unmasked self-attention in a decoder would leak future tokens during training
- Causal masking prevents query position i from attending to key positions j > i
- Ensures model predictions strictly depend on historical context

Token 1 sees [Token 1] → Token 2 sees [Token 1, Token 2] → Token 3 sees [Token 1, Token 2, Token 3] → Future tokens strictly hidden (-inf)

*Causal Attention Masking Concept*

**Notes** (6 min · outcomes CO2.LO1 · sources [C1] [C3] [C4]): When training autoregressive Transformer models like decoders, we want the model to predict the next word given past context. However, self-attention allows every token to see every other token in the sequence. To prevent token i from looking ahead at future target tokens j > i, we apply a causal mask that zeroes out attention probabilities for all future positions.

## 11. Constructing and Applying the Causal Mask

- Create an upper triangular mask matrix where forbidden positions (j > i) are marked
- Set forbidden positions to -infinity (or a large negative value like -1e9)
- Add the mask matrix to scaled dot product scores prior to Softmax computation
- Formula: Softmax( (Q K^T / sqrt(d_k)) + Mask )
- Since exp(-inf) = 0, softmax assigns exact 0.0 attention weight to future tokens

| Position | Key Pos 1 | Key Pos 2 | Key Pos 3 |
|---|---|---|---|
| Query Pos 1 | 0 | -inf | -inf |
| Query Pos 2 | 0 | 0 | -inf |
| Query Pos 3 | 0 | 0 | 0 |

*Additive Mask Matrix Structure for N = 3*

**Notes** (6 min · outcomes CO2.LO1 · sources [C3] [C4]): We implement causal masking by adding an upper-triangular matrix containing negative infinity (-inf) values above the main diagonal to the scaled dot product scores before passing them to the softmax function. Because e raised to -inf equals 0, the softmax outputs exact zero attention weight for all future positions j > i.

## 12. Worked Example: Masked Self-Attention Step-by-Step (Worked problem)

- Given sequence length N = 3 and scaled scores for Position 3: [0.5, 2.0, 2.0]
- All three keys are valid for Position 3 under causal mask (j <= i: 1, 2, 3 <= 3)
- Exponential terms for Position 3 raw scores: e^0.5 approx 1.65, e^2.0 approx 7.39, e^2.0 approx 7.39
- Sum of exponentials = 1.65 + 7.39 + 7.39 = 16.43
- Normalized softmax weights for Position 3: [1.65/16.43, 7.39/16.43, 7.39/16.43] = [0.10, 0.45, 0.45]
- Position 3 output is 0.10 * V_1 + 0.45 * V_2 + 0.45 * V_3

| Pos | Scaled Scores (Q K^T / sqrt(d_k)) | Causal Masked Scores | Softmax Attention Weights |
|---|---|---|---|
| 1 | [2.0, 1.0, 0.5] | [2.0, -inf, -inf] | [1.00, 0.00, 0.00] |
| 2 | [1.0, 1.0, 0.0] | [1.0, 1.0, -inf] | [0.50, 0.50, 0.00] |
| 3 | [0.5, 2.0, 2.0] | [0.5, 2.0, 2.0] | [0.10, 0.45, 0.45] |

*Step-by-Step Causal Masked Attention Scores & Weights*

**Notes** (7 min · outcomes CO2.LO1 · sources [C2] [C4]): Let's examine how masked self-attention works across positions. Position 1 can only attend to itself, getting weight [1.00, 0.00, 0.00]. Position 2 attends to positions 1 and 2, yielding [0.50, 0.50, 0.00]. For Position 3, raw scores are [0.5, 2.0, 2.0]. Computing exponentials yields 1.65, 7.39, 7.39. Dividing by their sum 16.43 gives softmax weights approximately [0.10, 0.45, 0.45].

## 13. Checking Understanding: Causal Masking Mechanics (Check)


**Why is negative infinity (-inf) used in the additive attention mask instead of 0?**

A. Because 0 added to logits would leave them unchanged, allowing future tokens to get non-zero softmax weight
B. Because softmax(0) equals infinity, which causes numerical underflow
C. Because negative infinity sets matrix values to zero prior to matrix multiplication
D. Because PyTorch does not support boolean masking during forward pass

*Answer: A. Because 0 added to logits would leave them unchanged, allowing future tokens to get non-zero softmax weight. Adding 0 to raw scores (logits) leaves them as-is, which would result in non-zero softmax probabilities e^score / sum. Adding -inf ensures exp(-inf) = 0, giving exact 0 softmax weight to future tokens. Option B is incorrect because exp(0) = 1, not infinity.*

**Notes** (5 min · outcomes CO2.LO1 · sources [C4]): Understanding why we use -inf for masking is essential. An additive mask modifies logits before softmax. If we added 0, the logit would remain unchanged and receive positive softmax probability. Adding -inf ensures e^(-inf) = 0.

## 14. Vectorized PyTorch Implementation

- Implement scaled dot-product attention efficiently in PyTorch without python loops
- Use torch.matmul for matrix multiplication across batch and sequence dimensions
- Generate lower-triangular causal mask using torch.tril
- Apply mask using tensor.masked_fill(mask == 0, float('-inf'))
- Compute softmax along the last dimension: dim=-1

```python
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / torch.sqrt(torch.tensor(d_k, dtype=torch.float32))
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    attn_weights = F.softmax(scores, dim=-1)
    output = torch.matmul(attn_weights, V)
    return output, attn_weights
```

*PyTorch Scaled Dot-Product Attention Function*

**Notes** (6 min · outcomes CO2.LO1 · sources [C4]): Here is clean, vectorized PyTorch code for scaled dot-product attention. Notice how K is transposed across its last two dimensions with transpose(-2, -1). We calculate scores, apply masked_fill where mask is false/0, evaluate softmax along dim=-1, and multiply by V.

## 16. Computational and Memory Complexity

- Matrix multiplication Q K^T requires O(N^2 * d_k) operations per sequence
- Attention weight matrix requires O(N^2) memory storage
- Quadratic scaling with sequence length N creates a bottleneck for long contexts
- Matrix multiplication with V requires O(N^2 * d_v) operations
- Motivates linear attention models and FlashAttention implementations

| Layer Type | Computational Complexity | Sequential Operations | Max Path Length |
|---|---|---|---|
| Self-Attention | O(N^2 * d) | O(1) | O(1) |
| Recurrent (RNN) | O(N * d^2) | O(N) | O(N) |
| Convolutional | O(k * N * d^2) | O(1) | O(log_k(N)) |

*Complexity Comparison of Sequence Layer Operations*

**Notes** (5 min · outcomes CO2.LO1 · sources [C3]): Self-attention provides direct O(1) path length between any two tokens, enabling excellent long-range modeling. However, computing and storing the N-by-N attention matrix incurs O(N^2) time and memory complexity. For long sequences (e.g., N > 4090), this quadratic bottleneck becomes severe, driving the development of FlashAttention and linear attention variants.

## 17. Summary: Scaled Dot-Product Self-Attention (Summary)

- Self-attention projects sequence inputs into Query, Key, and Value matrices
- Raw similarity scores Q K^T measure alignment between queries and keys
- Scaling by 1 / sqrt(d_k) prevents vanishing gradients caused by high-dimensional dot products
- Causal masking adds -inf to future positions to preserve autoregressive ordering
- Vectorized PyTorch implementation uses matmul, masked_fill, and row-wise softmax

Input Projections (Q, K, V) → Dot Product (Q K^T) → Scale (/ sqrt(d_k)) → Apply Causal Mask (+ M) → Softmax & Value Weighting

*Complete Scaled Dot-Product Attention Summary*

**Notes** (5 min · outcomes CO2.LO1 · sources [C3] [C4]): To summarize, scaled dot-product attention transforms input sequences into contextual representations by comparing Queries and Keys, scaling by sqrt(d_k), masking future positions with -inf, and taking a weighted sum of Values.
