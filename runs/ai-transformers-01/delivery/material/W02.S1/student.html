From Soft Lookup to Self-Attention

concept
  • Recap from Week 1: Attention acts as a soft key-value lookup mechanism
  • Input sequence embeddings X in R^(N x d_model) represent sequence tokens
  • Self-attention enables tokens within the same sequence to attend to each other
  • Queries (Q), Keys (K), and Values (V) are generated from the same input sequence
Input Embeddings X→Linear Transformations→Queries Q, Keys K, Values V→Scaled Dot-Product Attention→Contextual Outputs Z

Linear Projections for Queries, Keys, and Values

concept
  • Project input representations X using three learnable weight matrices
  • W^Q in R^(d_model x d_k), W^K in R^(d_model x d_k), W^V in R^(d_model x d_v)
  • Query matrix Q = X W^Q with dimensions N x d_k
  • Key matrix K = X W^K with dimensions N x d_k
  • Value matrix V = X W^V with dimensions N x d_v

The Scaled Dot-Product Attention Formulation

concept
  • Compute dot product similarity between queries and keys: Q K^T
  • Scale the raw dot product scores by 1 / sqrt(d_k)
  • Apply row-wise softmax to convert similarity scores into probabilities
  • Multiply softmax probabilities by values V to get context matrix Z
  • Equation: Attention(Q, K, V) = softmax(Q K^T / sqrt(d_k)) V
MatMul (Q, K^T)→Scale (1 / sqrt(d_k))→Softmax (Row-wise)→MatMul (Weights, V)

Sources: [C3] [C4]

6

Why Scale by the Square Root of Key Dimension?

concept
  • High-dimensional vectors produce large dot products under independent components
  • If Q_i and K_i are independent zero-mean unit-variance random variables, Var(Q . K) = d_k
  • Large magnitude logits push the softmax function into regions with tiny gradients
  • Scaling by 1 / sqrt(d_k) controls the variance back to 1.0
  • Prevents vanishing gradients during backward propagation

Sources: [C2] [C3]

Matrix Form and Dimension Tracking

concept
  • Input sequence matrix X has shape (N, d_model) where N is sequence length
  • Q and K have shape (N, d_k); Transposed K^T has shape (d_k, N)
  • Matrix product Q K^T has shape (N, N) representing all pair-wise attention scores
  • Softmax(Q K^T / sqrt(d_k)) preserves (N, N) matrix dimensions
  • Multiplying by V with shape (N, d_v) yields output Z of shape (N, d_v)
Matrix / TensorMathematical ExpressionShape
Queries (Q)X * W^Q(N, d_k)
Keys Transposed (K^T)(X * W^K)^T(d_k, N)
Raw Scores (Q K^T)Q * K^T(N, N)
Values (V)X * W^V(N, d_v)
Output (Z)Softmax(Q K^T / sqrt(d_k)) * V(N, d_v)

The Purpose of Causal Masking in Decoder Layers

concept
  • Autoregressive language models predict token i using only preceding tokens 1 to i - 1
  • Standard self-attention allows all tokens to attend to all other tokens bidirectionally
  • Unmasked self-attention in a decoder would leak future tokens during training
  • Causal masking prevents query position i from attending to key positions j > i
  • Ensures model predictions strictly depend on historical context
Token 1 sees [Token 1]→Token 2 sees [Token 1, Token 2]→Token 3 sees [Token 1, Token 2, Token 3]→Future tokens strictly hidden (-inf)

Sources: [C1] [C3] [C4]

Constructing and Applying the Causal Mask

concept
  • Create an upper triangular mask matrix where forbidden positions (j > i) are marked
  • Set forbidden positions to -infinity (or a large negative value like -1e9)
  • Add the mask matrix to scaled dot product scores prior to Softmax computation
  • Formula: Softmax( (Q K^T / sqrt(d_k)) + Mask )
  • Since exp(-inf) = 0, softmax assigns exact 0.0 attention weight to future tokens

Worked Example: Masked Self-Attention Step-by-Step

worked problem
  • Given sequence length N = 3 and scaled scores for Position 3: [0.5, 2.0, 2.0]
  • All three keys are valid for Position 3 under causal mask (j <= i: 1, 2, 3 <= 3)
  • Exponential terms for Position 3 raw scores: e^0.5 approx 1.65, e^2.0 approx 7.39, e^2.0 approx 7.39
  • Sum of exponentials = 1.65 + 7.39 + 7.39 = 16.43
  • Normalized softmax weights for Position 3: [1.65/16.43, 7.39/16.43, 7.39/16.43] = [0.10, 0.45, 0.45]
  • Position 3 output is 0.10 * V_1 + 0.45 * V_2 + 0.45 * V_3

Checking Understanding: Causal Masking Mechanics

check

Why is negative infinity (-inf) used in the additive attention mask instead of 0?

Adding 0 to raw scores (logits) leaves them as-is, which would result in non-zero softmax probabilities e^score / sum. Adding -inf ensures exp(-inf) = 0, giving exact 0 softmax weight to future tokens. Option B is incorrect because exp(0) = 1, not infinity.

Vectorized PyTorch Implementation

concept
  • Implement scaled dot-product attention efficiently in PyTorch without python loops
  • Use torch.matmul for matrix multiplication across batch and sequence dimensions
  • Generate lower-triangular causal mask using torch.tril
  • Apply mask using tensor.masked_fill(mask == 0, float('-inf'))
  • Compute softmax along the last dimension: dim=-1
import torch
import torch.nn.functional as F

def scaled_dot_product_attention(Q, K, V, mask=None):
    d_k = Q.size(-1)
    scores = torch.matmul(Q, K.transpose(-2, -1)) / torch.sqrt(torch.tensor(d_k, dtype=torch.float32))
    if mask is not None:
        scores = scores.masked_fill(mask == 0, float('-inf'))
    attn_weights = F.softmax(scores, dim=-1)
    output = torch.matmul(attn_weights, V)
    return output, attn_weights

Computational and Memory Complexity

concept
  • Matrix multiplication Q K^T requires O(N^2 * d_k) operations per sequence
  • Attention weight matrix requires O(N^2) memory storage
  • Quadratic scaling with sequence length N creates a bottleneck for long contexts
  • Matrix multiplication with V requires O(N^2 * d_v) operations
  • Motivates linear attention models and FlashAttention implementations

Summary: Scaled Dot-Product Self-Attention

summary
  • Self-attention projects sequence inputs into Query, Key, and Value matrices
  • Raw similarity scores Q K^T measure alignment between queries and keys
  • Scaling by 1 / sqrt(d_k) prevents vanishing gradients caused by high-dimensional dot products
  • Causal masking adds -inf to future positions to preserve autoregressive ordering
  • Vectorized PyTorch implementation uses matmul, masked_fill, and row-wise softmax
Input Projections (Q, K, V)→Dot Product (Q K^T)→Scale (/ sqrt(d_k))→Apply Causal Mask (+ M)→Softmax & Value Weighting

Sources: [C3] [C4]
