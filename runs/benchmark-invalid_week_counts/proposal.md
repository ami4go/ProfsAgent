## 3. Course description

This course examines modern AI-native software development, focusing on how developers collaborate with coding agents. Designed for third- and fourth-year undergraduate students, the curriculum covers defining intent, structuring development workflows, and coordinating AI tools. Students learn to configure AI-assisted environments, translate high-level functional requirements into executable specifications, and analyze execution traces to diagnose agent-driven workflow failures. Additionally, they evaluate the correctness, reliability, and security risks of agent-generated code, and benchmark end-to-end software pipelines. The course is taught through three hours of lectures, one tutorial hour, and two practical lab hours per week, culminating in a hands-on project. Crucially, this is a practical, workflow-oriented engineering course rather than a general introduction to artificial intelligence, a traditional programming class, or a purely theoretical treatment of large language models.

## Appendix F — Rationales (G11)

- **sequencing rationale:** The course progresses logically from environment setup to pipeline integration. Students first configure AI-native environments (M1), building on foundational programming and unit testing prerequisites from CSE201. They then design specifications (M2) and trace workflow failures (M3). This enables them to perform automated testing and code reviews (M4), culminating in designing and benchmarking end-to-end pipelines (M5). This sequence ensures students master individual agent interactions before orchestrating complex, multi-agent software engineering pipelines.
- **assessment rationale:** The assessment mix balances theoretical understanding and practical application. Written exams (midsem 20%, endsem 30%) evaluate conceptual knowledge of context engineering and workflow tracing (CO2, CO3). Practical labs (10%) and assignments (20%) assess hands-on capabilities in environment configuration and automated testing (CO1, CO4). Finally, the term project (20%) requires students to design, evaluate, and benchmark a complete, end-to-end AI-native software pipeline (CO5), aligning with the highest cognitive levels of the course.
- **positioning rationale:** Unlike CSE201 (foundational programming) or CSE701 (research-oriented mining of software repositories), this course focuses on operational AI-native workflows. It differs from CSE581 (traditional systems analysis) and CSE582 (software product lines) by centering on specification-driven development using coding agents. While CSE594A targets algorithmic problem solving and AI501 covers core machine learning theory, this course applies software engineering practices to agentic workflows, complementing the open-source tools in CSE583 and LLM architectures in CSE665.
