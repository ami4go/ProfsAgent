## 3. Course description

This course examines modern AI-native software development, where developers collaborate with increasingly capable coding agents. It covers how to define intent, provide effective context, structure development workflows, and coordinate AI tools. Students gain practical experience designing and evaluating agent-assisted software development processes. Through structured lectures, tutorials, and laboratory sessions, students learn to configure AI coding assistants and developer workflows, construct agentic tools, Model Context Protocol integrations, and agent skills, assess executable specifications and development plans from requirements documents, analyze iterative development loops and software factory pipelines, and design automated evaluation frameworks for agent-assisted software systems. The course is designed for senior undergraduate students and emphasizes a workflow-oriented understanding through hands-on development and experimentation. It should NOT become a general introduction to AI or machine learning.

## Appendix F — Rationales (G11)

- **sequencing rationale:** The modules progress from foundational AI-native development paradigms and workspace configuration to advanced agentic tooling, specification-driven requirements, iterative software factories, and reliability frameworks. This sequence builds directly upon the programming and software engineering fundamentals required from CSE201.
- **assessment rationale:** The assessment mix comprises quizzes, assignments, reports, midsem and endsem examinations, and a practical project. This combination effectively measures both conceptual understanding and the students' ability to practically apply agent-assisted workflows, construct tools, and design evaluation frameworks matching the cognitive levels of the course outcomes.
- **positioning rationale:** Unlike CSE701 which investigates AI techniques for software engineering research and repository mining, or CSE594A which focuses on agentic reasoning for algorithmic and mathematical problem solving, this course is specifically tailored to software engineering workflows, coding agents, and practical agent-assisted development.
