## 2 · Course context (paste as a text source)

```text
COURSE: Software Development using AI (IIIT-Delhi, level 3xx, 3/4-year B.Tech students)
LECTURE: W02.L2 · week 2 · Coding agents and context engineering (60 minutes)

LEARNING OUTCOMES (what students must be able to do):
- Configure custom tool integrations within agent workspaces using model context protocols, with all public tests passing and no warnings from the configured static analyser.

STUDENTS ALREADY KNOW:
- Model context protocols and architecture (week 1)

THIS LECTURE, PART BY PART:
1. Anatomy of coding agent workspaces and execution lifecycle (15 min, concept)
   Teaches: Students will understand the core architectural layers of an autonomous coding agent workspace, including environment virtualization, state tracking, and scratchpad management. They will trace how an agent transitions from prompt ingestion to planning, tool dispatch, and observation intake.
   Key terms: coding agent, agent workspace, execution lifecycle, state tracking, observation loop, scratchpad
2. Context engineering strategies for constrained context windows (15 min, mechanism)
   Teaches: Students will learn context engineering mechanisms such as selective file tree pruning, sliding context windows, and dynamic relevance filtering. They will evaluate trade-offs between full repository indexing and lightweight context token budgets to prevent model distraction.
   Key terms: context engineering, context window, token budget, relevance filtering, context compaction, prompt caching
3. Structuring MCP tool schemas and workspace descriptors (15 min, mechanism)
   Teaches: Students will learn how to structure tool definitions using Model Context Protocol (MCP) JSON schemas so agents can discover and invoke workspace tools cleanly. They will specify required arguments, return payloads, and environment permissions according to MCP interface specifications.
   Key terms: Model Context Protocol, tool schema, JSON-RPC, workspace descriptor, tool discovery, parameter validation
4. Evaluating context pollution and tool discovery trade-offs (15 min, comparison)
   Teaches: Students will analyse the failure modes caused by context pollution when exposing too many MCP tools or verbose tool definitions to a coding agent. They will compare lazy tool registration against global tool injection in terms of latency, token cost, and hallucinated invocations.
   Key terms: context pollution, lazy tool registration, hallucinated invocation, token overhead, tool selection accuracy

COMES LATER (do not teach here):
- Custom tool integrations using model context protocols (week 3)
```
