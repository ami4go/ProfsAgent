## 2 · Course context (paste as a text source)

```text
COURSE: Software Development using AI (IIIT-Delhi, level 3xx, 3/4-year B.Tech students)
LECTURE: W03.L2 · week 3 · Custom tool integrations using model context protocols (120 minutes)

LEARNING OUTCOMES (what students must be able to do):
- Configure custom tool integrations within agent workspaces using model context protocols, with all public tests passing and no warnings from the configured static analyser.

STUDENTS ALREADY KNOW:
- Coding agents and context engineering (week 2)

THIS LECTURE, PART BY PART:
1. Architecture of Model Context Protocol (MCP) clients and servers (15 min, concept)
   Teaches: Students will understand the client-server architecture of the Model Context Protocol (MCP) and how LLM agent workspaces communicate with external tools. They will identify the roles of host applications, MCP clients, and MCP servers during session initialization and tool exposure.
   Key terms: Model Context Protocol, MCP Client, MCP Server, Host Application, Transport Layer, Stdio Transport
2. JSON-RPC 2.0 protocol format for tool discovery and calls (15 min, mechanism)
   Teaches: Students will learn how JSON-RPC 2.0 messages are structured for tools/list and tools/call requests in MCP. They will examine request IDs, method headers, parameter payloads, and response objects transmitted over standard streams.
   Key terms: JSON-RPC 2.0, tools/list, tools/call, Request Envelope, Response Payload, Stdio Messaging
3. Defining strict input JSON schemas for MCP tools (15 min, mechanism)
   Teaches: Students will learn how to write precise JSON Schema definitions for tool parameters to guide LLM tool calling. They will specify required fields, parameter data types, descriptions, and validation constraints that prevent ambiguous agent invocations.
   Key terms: JSON Schema, inputSchema, Type Constraints, Required Properties, Parameter Descriptions, Tool Metadata
4. Implementing an MCP server using an official SDK (20 min, worked example)
   Teaches: Students will walk through building a lightweight MCP server using an official SDK. They will observe how decorated functions are exposed as callable tools and how incoming JSON arguments are parsed automatically.
   Key terms: MCP SDK, Server Initialization, Tool Handler, Decorator Syntax, Async Execution
5. Activity: Writing and running a custom MCP server tool (25 min, activity)
   Teaches: Students will write a custom tool function on an MCP server that executes local file or system operations and returns formatted content blocks. They will test the server execution using standard input streams to verify correct responses.
   Key terms: Tool Implementation, TextContent, CallToolResult, Stdio Execution, Local Tool Testing
6. Configuring workspace settings to discover custom MCP servers (15 min, mechanism)
   Teaches: Students will configure an agent workspace JSON configuration file to register their custom server executable and command-line arguments. They will verify that the agent successfully discovers and surfaces the new tool capabilities.
   Key terms: mcpServers Config, Workspace Configuration, Executable Path, Environment Variables, Server Discovery
7. Handling execution errors and returning structured MCP errors (15 min, mechanism)
   Teaches: Students will learn how to catch internal tool execution failures and map them to structured MCP error responses using the isError flag. They will distinguish between runtime exceptions inside tool execution and protocol-level transport failures.
   Key terms: isError Flag, CallToolResult, Structured Error Messages, Exception Handling, Protocol Errors
```
