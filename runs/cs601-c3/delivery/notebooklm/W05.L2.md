## 2 · Course context (paste as a text source)

```text
COURSE: Software Development using AI (IIIT-Delhi, level 3xx, 3/4-year B.Tech students)
LECTURE: W05.L2 · week 5 · Spec-driven development frameworks (30 minutes)

LEARNING OUTCOMES (what students must be able to do):
- Translate module requirements into executable specifications using spec-driven development frameworks, meeting the stated interface specification for every public method.

STUDENTS ALREADY KNOW:
- Software requirements and requirements engineering (week 4)

THIS LECTURE, PART BY PART:
1. Foundations of Spec-Driven Development Frameworks (15 min, concept)
   Teaches: Students will understand the core workflow of spec-driven development (SDD) where formal specifications serve as the single source of truth prior to implementation. They will analyze how SDD differs from traditional Test-Driven Development (TDD) by decoupling interface contracts from language-specific test code. Students will also learn how LLMs and static analyzers leverage these frameworks to enforce architectural consistency.
   Key terms: Spec-Driven Development, Executable Specification, Interface Contract, Single Source of Truth, API-First
2. Anatomy of Executable Specifications and Schemas (15 min, mechanism)
   Teaches: Students will examine the internal structural requirements of executable specifications using tools like OpenAPI, JSON Schema, or TypeSpec. They will learn how type definitions, input constraints, and response schemas define public interface signatures. Students will identify how machine-readable constraints enable automated contract validation before any code is generated.
   Key terms: JSON Schema, TypeSpec, Preconditions, Postconditions, Contract Validation, Schema Validation

COMES LATER (do not teach here):
- Requirements to executable specifications and code generation (week 6)
```
