## 2 · Course context (paste as a text source)

```text
COURSE: Software Development using AI (IIIT-Delhi, level 3xx, 3/4-year B.Tech students)
LECTURE: W07.L2 · week 7 · Iterative development and loop engineering (120 minutes)

LEARNING OUTCOMES (what students must be able to do):
- Trace execution logs produced by coding agents during iterative loop engineering tasks, recording all control-flow steps across the log artifact.

THIS LECTURE, PART BY PART:
1. Iterative Loop Engineering Overview (15 min, concept)
   Teaches: Students learn the definition of iterative loop engineering, its role in AI‑assisted coding, and the high‑level phases of a coding agent's generate‑test‑refactor cycle.
   Key terms: iterative loop engineering, coding agent, generate-test-refactor, AI-assisted coding
2. Execution Log Structure and Fields (15 min, concept)
   Teaches: Students identify the standard schema of an execution log, including timestamp, event type, agent identifier, and payload, and understand how each field maps to a control‑flow step.
   Key terms: log schema, timestamp, event type, agent identifier, payload
3. Control‑Flow Step Taxonomy (15 min, mechanism)
   Teaches: Students categorize the distinct step types recorded in logs—function calls, loop iterations, conditional branches, and agent decision points—and explain how each appears in the log artifact.
   Key terms: function call, loop iteration, conditional branch, agent decision, step taxonomy
4. Instrumentation and Logging Frameworks (15 min, demo)
   Teaches: Students observe a live demo of adding instrumentation hooks to a coding agent using Python's logging module and OpenTelemetry, seeing how logs are emitted in real time.
   Key terms: instrumentation, logging framework, OpenTelemetry, hook, real‑time emission
5. Worked Example: Simple Agent Loop Trace (15 min, worked example)
   Teaches: Students follow a step‑by‑step trace of a toy generate‑test‑refactor agent, mapping each log entry to source‑code changes and identifying the control‑flow path.
   Key terms: toy agent, generate-test-refactor, trace mapping, source‑code change, control‑flow path
6. Activity: Instrument a Toy Agent (15 min, activity)
   Teaches: Students modify a provided skeleton agent to emit structured logs, run it on a sample task, and verify that all control‑flow steps appear in the output log.
   Key terms: skeleton agent, structured log, sample task, verification, control‑flow coverage
7. Mapping Log Steps to Code Changes (15 min, mechanism)
   Teaches: Students learn techniques to correlate log entries with diffs in the codebase, using timestamps and agent IDs to reconstruct the iterative development narrative.
   Key terms: log correlation, code diff, timestamp alignment, agent ID, development narrative
8. Pitfalls and Best Practices in Tracing (15 min, comparison)
   Teaches: Students compare common logging anti‑patterns—missing context, inconsistent granularity, and timestamp drift—with recommended practices for reliable traceability.
   Key terms: anti‑pattern, missing context, granularity, timestamp drift, best practice

COMES LATER (do not teach here):
- Iterative development logs and software factory outputs (week 8)
```
