## 2 · Course context (paste as a text source)

```text
COURSE: Software Development using AI (IIIT-Delhi, level 3xx, 3/4-year B.Tech students)
LECTURE: W09.L2 · week 9 · Testing and validation in iterative development (30 minutes)

LEARNING OUTCOMES (what students must be able to do):
- Analyze execution traces produced by coding agents during iterative loop engineering tasks, for a supplied log file of at most 2000 lines, identifying at least three distinct failure causes with supporting log evidence.

STUDENTS ALREADY KNOW:
- Software factories and execution trace analysis (week 9)

THIS LECTURE, PART BY PART:
1. Trace structure and metadata (15 min, concept)
   Teaches: Students learn the standard fields of an agent execution trace: timestamps, event types, tool calls, return values, and error codes. They understand how these fields map to the iterative loop steps and why consistent formatting matters for automated parsing.
   Key terms: timestamp, event_type, tool_call, return_value, error_code, iteration
2. Worked example: diagnosing tool misuse (15 min, worked example)
   Teaches: The instructor walks through a 500-line trace where the agent repeatedly calls a file‑write tool with an invalid path. Students see how to locate the offending calls, correlate error codes, and confirm the root cause with log evidence.
   Key terms: tool_misuse, invalid_path, error_code, root_cause, log_evidence
```
