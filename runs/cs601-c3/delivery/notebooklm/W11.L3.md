## 2 · Course context (paste as a text source)

```text
COURSE: Software Development using AI (IIIT-Delhi, level 3xx, 3/4-year B.Tech students)
LECTURE: W11.L3 · week 11 · Reliable and safe trustworthy software architectures (60 minutes)

LEARNING OUTCOMES (what students must be able to do):
- Assess automated testing pipelines for AI-native software factories, for a supplied multi-component software project, justifying each design decision against at least one stated reliability requirement.

STUDENTS ALREADY KNOW:
- Automated testing and evaluation mechanisms (week 10)

THIS LECTURE, PART BY PART:
1. AI-native factory pipeline architecture overview (15 min, concept)
   Teaches: Students will understand the high-level structure of an AI-native software factory, identifying the major pipeline components such as data ingestion, model training, validation, and deployment. They will recognize how these components interact to form an end-to-end automated workflow.
   Key terms: pipeline, data ingestion, model training, validation, deployment, automation
2. Automated testing stages in AI pipelines (15 min, mechanism)
   Teaches: Students will learn the concrete testing stages used in AI-native pipelines: unit tests for code, integration tests for data flows, model validation tests (accuracy, fairness), and data drift detection. They will be able to describe the purpose and typical tooling for each stage.
   Key terms: unit testing, integration testing, model validation, data drift detection, test tooling
3. Mapping reliability requirements to pipeline stages (15 min, comparison)
   Teaches: Students will analyse a set of reliability requirements (e.g., reproducibility, latency, fault tolerance) and map each requirement to specific pipeline stages and testing mechanisms. They will compare how different requirements influence test design choices.
   Key terms: reliability requirements, reproducibility, latency, fault tolerance, mapping
4. Worked example: assessing sample pipeline reliability (15 min, worked example)
   Teaches: Through a guided walkthrough, students will evaluate a provided sample AI pipeline against a list of reliability requirements, justifying each assessment decision with concrete evidence from the pipeline's test configuration. They will practice the evaluation criteria needed for the final assessment.
   Key terms: worked example, assessment, justification, evidence, criteria

COMES LATER (do not teach here):
- Deployment and reliability metric evaluation (week 12)
```
