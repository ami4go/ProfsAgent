# Review quiz · W01.L1 · Developer workflows and AI-assisted coding

## Review quiz (10 min)

1. How does the developer workflow fundamentally shift when transitioning from traditional edit-compile-debug loops to AI-augmented development?
   - A. Developers no longer need to write design specifications or document interfaces.
   - B. Developers replace manual testing entirely with automated model verifications.
   - C. Code compilation occurs automatically after every keystroke via remote inference servers.
   - D. The core routine shifts toward continuous speculative drafting and prompt refinement.

2. In the architecture of a modern AI code assistant, what is the primary role of the local IDE extension?
   - A. Compiling code and checking type correctness remote endpoints.
   - B. Executing deep learning model inference locally on client hardware.
   - C. Generating synthetic datasets for model fine-tuning.
   - D. Gathering telemetry, local buffers, and cursor position to pass to the orchestrator.

3. What primary trade-off occurs when expanding the context window scope to include more surrounding file content in autocompletion prompts?
   - A. Broader context increases generation latency while providing more accurate background.
   - B. Larger context budgets eliminate the possibility of model hallucinations.
   - C. A larger token budget speeds up model inference time.
   - D. Including open editor tabs automatically reduces memory usage on the client machine.

4. Which prompt contextualisation approach best ensures deterministic, correct code generation for a scoped task like a utility function?
   - A. Providing concise prompts without explicit type annotations to allow model flexibility.
   - B. Including entire workspace repositories to maximize context budget usage.
   - C. Relying on open-ended conversational requests without structural constraints.
   - D. Supplying explicit type signatures, interfaces, and minimal input-output examples.

5. Why might a developer choose a docked chat interface over passive inline ghost text when designing complex new logic?
   - A. Inline ghost text cannot generate multi-line completions.
   - B. Docked chat directly edits code buffers without developer approval.
   - C. Docked chat operates completely offline without inference latency.
   - D. Ghost text can create cognitive fatigue by continuously interrupting focus with immediate proposals.

6. During active development in an AI-assisted IDE, what happens to prompt payloads when a developer opens a relevant interface tab?
   - A. The model pauses all code completion until manual prompt submission.
   - B. The assistant purges all recent language server diagnostic logs.
   - C. The ambient context dynamically incorporates the new tab's interfaces into model prompts.
   - D. The IDE re-initializes the extension client entirely.

7. A developer switches git branches to an older codebase, but the assistant suggests methods from an API introduced only in the newer branch. What issue is demonstrated here?
   - A. Over-contextualised prompt formatting.
   - B. Stale context carrying over across workspace environment state changes.
   - C. Context window token exhaustion.
   - D. Language Server Protocol diagnostic failure.

8. What combination of quality gates provides the most reliable guardrail before committing AI-assisted code to production?
   - A. Automated static analysis, local test suites, and strict human code review.
   - B. Restricting AI usage exclusively to writing documentation and docstrings.
   - C. Disabling all inline code completion tools during refactoring.
   - D. Solely relying on model self-verification prompts before rendering code.

## Answers

- Quiz 1: **D**: AI-augmented workflows transform the traditional linear edit-compile-debug loop into continuous speculative drafting, where developers refine prompts and evaluate model suggestions iteratively. (W01.L1.C1)
- Quiz 2: **D**: The local IDE extension collects real-time editor state such as local buffer snippets, cursor position, and telemetry before handing them off to an orchestrator for prompt assembly. (W01.L1.C2)
- Quiz 3: **B**: Expanding the context scope gives the model useful ambient information, but processing more tokens increases prompt processing and overall inference latency. (W01.L1.C3)
- Quiz 4: **D**: Explicit type signatures, explicit interface boundaries, and minimal examples constrain the generative search space without exhausting context token limits. (W01.L1.C4)
- Quiz 5: **D**: Inline ghost text can impose cognitive load and interrupt deep thought during complex architecture work, whereas conversational chat allows active, intentional elicitation when needed. (W01.L1.C5)
- Quiz 6: **C**: Modern AI IDEs dynamically observe editor state changes, such as opening new tabs or importing interfaces via LSP, updating the prompt payload sent to the model in real time. (W01.L1.C6)
- Quiz 7: **B**: Stale context occurs when an assistant retains cached snippets or file states from previous sessions or branches, causing suggestions that are invalid for the active workspace state. (W01.L1.C7)
- Quiz 8: **A**: Automated linting and test suites catch immediate syntax and runtime errors, while human code review ensures overall logic correctness and prevents silent quality degradation. (W01.L1.C8)
