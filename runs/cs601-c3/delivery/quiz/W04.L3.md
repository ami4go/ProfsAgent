# Review quiz · W04.L3 · Software requirements and requirements engineering

## Review quiz (0 min)

1. According to standard spec-driven guidelines and use case standards, which element is mandatory in a formal use case specification?
   - A. Internal database schema design
   - B. Target programming language version
   - C. Hardware memory allocation limits
   - D. Primary actor and goal statement

2. Why do requirements engineering standards like IEEE 830 emphasize separating behavioral specifications from implementation details?
   - A. To focus on functional external behaviors and system interactions
   - B. To hide requirement documents from non-technical stakeholders
   - C. To eliminate the need for software testing
   - D. To mandate a specific programming language for developers

3. An e-commerce application sends transaction verification requests to an external payment gateway during checkout. How is the external payment gateway classified in this system's use case model?
   - A. Primary actor inside the system boundary
   - B. Use case action within the system process
   - C. Secondary external actor outside the system boundary
   - D. Internal actor within the system boundary

4. A developer modeling an automated library system labels an internal database update script as an external primary actor. Is this classification accurate?
   - A. Yes, because all background processes are treated as primary actors
   - B. No, because database scripts must always be classified as human secondary actors
   - C. No, because internal components reside within the system boundary and are not actors
   - D. Yes, because automated scripts alter database state

## Answers

- Quiz 1: **D**: Standard use case specifications mandate identifying functional elements such as the primary actor and their intended goal rather than technical implementation details. (W04.L3.C1)
- Quiz 2: **A**: IEEE 830 guidelines focus on defining software requirements in terms of external interactions and functional behaviors without locking the design into specific low-level coding implementations. (W04.L3.C1)
- Quiz 3: **C**: External services that interface with the system to fulfill a request are categorized as secondary actors residing outside the system boundary. (W04.L3.C2)
- Quiz 4: **C**: Actors must be external entities interacting with the system across its boundary; internal software modules or automated scripts are part of the system itself. (W04.L3.C2)
