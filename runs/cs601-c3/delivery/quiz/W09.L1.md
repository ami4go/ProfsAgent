# Review quiz · W09.L1 · Software factories and execution trace analysis

## Recap of the previous lecture (5 min)

1. Which software factory artifact should you inspect to verify the complete list of declared dependencies and output binary schemas for a specific build?
   - A. Test execution summary
   - B. Tool invocation logs
   - C. Commit metadata
   - D. Artifact manifest

2. A test suite passes on the first run, fails on the second run without code changes, and passes on the third. Which seeded defect category does this signature indicate?
   - A. Flaky test
   - B. Missing dependency
   - C. Resource leak
   - D. Configuration drift

3. You need to extract failure messages specifically from JSON-formatted factory build logs. Which command line approach is most appropriate?
   - A. sed -n '/ERROR/p' build.log
   - B. grep -i "error" build.log
   - C. tail -n 50 build.log
   - D. jq '.steps[] | select(.status=="failed") | .error' build.log

## Review quiz (10 min)

1. Why are execution traces essential when coding agents run in iterative software engineering loops?
   - A. They provide diagnostic history to track agent actions and identify failure causes across iterations.
   - B. They encrypt API keys used during coding loop execution.
   - C. They eliminate the need for writing automated unit tests.
   - D. They directly edit source code when an agent makes a syntax error.

2. When navigating a large development log, which structural element helps an engineer quickly isolate actions taken during a specific attempt by the coding agent?
   - A. Memory address pointers
   - B. Iteration IDs
   - C. Source code line limits
   - D. Encrypted hash signatures

3. An agent trace shows repeated HTTP retries while fetching external packages, followed by a build failure. Which failure category does this trace signature indicate?
   - A. Logic regression
   - B. Environment misconfiguration
   - C. Dependency resolution error
   - D. Memory leak

4. How does using a custom parser script improve the analysis of raw software factory logs?
   - A. It reduces the total line count of the codebase being generated.
   - B. It replaces the agent's LLM with a rule-based engine.
   - C. It converts unstructured raw logs into structured JSON for automated filtering and processing.
   - D. It automatically fixes broken code logic found within the execution trace.

5. An agent's execution log terminates abruptly with an error indicating a missing environment variable. Which log excerpt provides direct evidence for an environment misconfiguration failure?
   - A. `[Iteration 4] SyntaxError: unexpected indent at line 42`
   - B. `[Iteration 1] Fatal error: missing required key 'DB_PORT' in environment context`
   - C. `[Iteration 2] Executing command: pytest unit_tests/`
   - D. `[Iteration 3] Git diff: updated connection logic in db.py`

6. You observe an agent retrying package installation multiple times with different version tags before failing. Which log evidence best proves a dependency resolution failure?
   - A. The line count of the generated source file.
   - B. The dependency graph log lines detailing conflicting version requirements.
   - C. The timestamp difference between iteration starts.
   - D. The total CPU utilization reported by the host platform.

7. During iteration 3, an agent's code change causes previously passing unit tests to fail. Which log artifacts should be correlated to verify a logic regression failure?
   - A. The test result diff showing new test failures and the corresponding commit diff.
   - B. The agent's prompt history and external API response times.
   - C. Network trace packets captured during dependency download.
   - D. System uptime logs and disk I/O metrics.

8. When evaluating failure severity across trace logs using a rubric, why is an environment misconfiguration generally ranked as higher severity than a single logic regression?
   - A. Severity rubrics evaluate trace length rather than failure impact.
   - B. Logic regressions are automatically repaired by the underlying operating system.
   - C. Environment misconfigurations block execution entirely across all iterations, preventing any progress.
   - D. Environment misconfigurations always require manual rewrites of core algorithms.

## Answers

- Recap 1: **D**: The artifact manifest defines the output schemas and declared dependencies of built artifacts, whereas logs capture runtime execution details. (W08.L2.C1)
- Recap 2: **A**: Non-deterministic test failures occurring under identical code conditions are the characteristic signature of a flaky test defect. (W08.L2.C2)
- Recap 3: **D**: Using jq allows structural field projection and conditional filtering on structured JSON logs, which line-oriented tools like grep cannot reliably do. (W08.L2.C3)
- Quiz 1: **A**: Execution traces record the step-by-step history of agent operations and tool calls during iterative loops, making it possible to diagnose why and where a failure occurred. (W09.L1.C1)
- Quiz 2: **B**: Iteration IDs partition standardized logs into distinct development cycles, allowing systematic navigation across high-line-count log files. (W09.L1.C2)
- Quiz 3: **C**: Repeated fetch retries and failure to resolve required package versions are characteristic trace signatures of dependency resolution errors. (W09.L1.C3)
- Quiz 4: **C**: Parser scripts parse raw log files into structured JSON formats, enabling automated querying and systematic evidence extraction. (W09.L1.C4)
- Quiz 5: **B**: Citing explicit log lines showing missing system environment variables provides direct log evidence for environment misconfiguration failures. (W09.L1.C5)
- Quiz 6: **B**: Dependency graph lines showing version conflicts and failed fetch retries provide definitive evidence for dependency resolution failures. (W09.L1.C6)
- Quiz 7: **A**: Detecting a logic regression requires correlating behavioral changes (test result diffs) with the specific commit diff lines introduced in that iteration. (W09.L1.C7)
- Quiz 8: **C**: Evaluating failure impact shows that environment failures halt execution completely across iterations, making them higher severity than localized logic regressions. (W09.L1.C8)
