# Review quiz · W09.L2 · Testing and validation in iterative development

## Review quiz (0 min)

1. Why is consistent formatting of metadata (such as event types, timestamps, and error codes) critical in agent execution traces?
   - A. It automatically fixes failed tool calls without human intervention.
   - B. It allows automated tools to reliably parse and map execution steps across iterative loops.
   - C. It compresses the log file size to reduce disk overhead.
   - D. It prevents the agent from making invalid syntax calls during execution.

2. Which set of trace fields provides direct log evidence that a specific tool invoked by an agent failed during an iteration step?
   - A. iteration number and timestamp
   - B. event_type and timestamp only
   - C. tool_call, return_value, and error_code
   - D. timestamp and iteration number

3. An execution trace shows an agent calling a file-write tool 10 times in a row, each returning an error code indicating the destination directory does not exist. What is the root cause shown by this trace?
   - A. The file system permissions were revoked mid-execution.
   - B. The agent is misusing the tool by supplying an invalid path and failing to handle the returned error.
   - C. The system experienced an intermittent network timeout across iterations.
   - D. The trace logger dropped event records between iterations.

4. When analyzing a trace log to diagnose why an agent failed an editing task, how do you verify if tool misuse is the root cause?

## Answers

- Quiz 1: **B**: Consistent trace metadata formatting allows automated parsers to reliably extract step outputs, map iteration loops, and spot execution failures. (W09.L2.C1)
- Quiz 2: **C**: Correlating the tool_call with its returned output (return_value) and explicit error_code provides direct evidence of whether and why the tool execution failed. (W09.L2.C1)
- Quiz 3: **B**: Repeated tool calls with bad arguments yielding the same error code demonstrate tool misuse, where the agent repeatedly inputs an invalid path without interpreting the error return code. (W09.L2.C2)
- Quiz 4: **Locate the repeated tool_call entries in the trace, check if the input arguments (such as file paths) are invalid, and confirm that the corresponding return_value or error_code shows a failure.**: Diagnosing tool misuse requires inspecting the invocation arguments within tool_call log entries and matching them against failing error_code or return_value outputs. (W09.L2.C2)
