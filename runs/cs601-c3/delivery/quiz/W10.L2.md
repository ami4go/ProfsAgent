# Review quiz · W10.L2 · Automated testing and evaluation mechanisms

## Recap of the previous lecture (5 min)

1. You need to quickly count how many times HTTP 500 error codes appear in a 2000-line JSON execution trace file. Which command-line approach is most appropriate?
   - A. Use awk to replace all timestamps with text strings before scanning with grep.
   - B. Pass the raw trace into an LLM prompt to estimate error frequencies without parsing.
   - C. Use jq to parse the JSON logs, filter by the error code field, and count occurrences.
   - D. Manually scroll through the raw text file in an editor to count 500 error strings.

2. An engineer suspects an agent failed due to a missing permission in iteration 3, but modifies the source code without inspecting the log context. Which step of the systematic trace analysis workflow was skipped?
   - A. Running initial setup scripts before trace collection.
   - B. Searching for signature patterns and collecting log evidence to validate the hypothesis.
   - C. Formulating initial failure hypotheses.
   - D. Segmenting the trace by iteration index.

3. During log analysis, an agent repeatedly executes the exact same shell command without advancing state across multiple log segments. What failure type does this represent, and what log evidence confirms it?
   - A. A version mismatch, confirmed by dynamic library load warnings.
   - B. A permission error, confirmed by EACCES denial flags in step outputs.
   - C. A hardware crash, confirmed by sudden termination of process IDs.
   - D. A logic loop, confirmed by repeating sequential log lines with identical step actions.

## Review quiz (10 min)

1. Why do traditional assertion-based unit tests (e.g., assert output == expected) often fail when testing AI-native software components?
   - A. Standard test runners cannot execute matrix operations in Python.
   - B. AI software components do not support function calls or parameters.
   - C. Probabilistic and non-deterministic model outputs introduce the test oracle problem.
   - D. AI models are too large to execute inside standard unit test frameworks.

2. You need to test an image classification model without labeled ground-truth data for modified inputs. You pass an image and a slightly rotated version of the same image, expecting the predicted class to remain identical. Which mechanism are you using?
   - A. Metamorphic testing
   - B. Model calibration profiling
   - C. Data drift detection
   - D. Contract schema validation

3. An upstream service updates a pipeline feature from integer values (e.g., age 25) to categorical string ranges (e.g., '20-30'). The deployed ML model silently generates incorrect predictions without crashing. Which mechanism prevents this integration failure?
   - A. Data drift detection
   - B. Schema validation and contract testing
   - C. Fairness disparity measurement
   - D. Property-based unit testing

4. A deployed fraud detection model assigns a probability score of 0.70 to a batch of transactions. In practice, exactly 70% of these transactions turn out to be fraudulent. Which model evaluation metric does this describe?
   - A. Recall
   - B. Model calibration
   - C. Adversarial robustness
   - D. Disparate impact

5. A real-time autonomous vehicle perception service requires model outputs within 15 milliseconds to execute safety maneuvers. Which system-level metric dominates the testing and SLA requirements for this service?
   - A. Data drift rate
   - B. Training throughput
   - C. Disparate impact
   - D. Latency

6. You are designing the testing architecture for a high-risk medical AI application where labeled edge cases are scarce but prediction errors carry high real-world penalties. Which testing strategy balances risk tolerance and resource constraints?
   - A. Rely exclusively on offline synthetic accuracy benchmarks to minimize resource costs.
   - B. Rely only on manual user-acceptance testing right before major production deployments.
   - C. Combine metamorphic testing for edge-case coverage with contract testing and drift monitoring for production pipelines.
   - D. Deploy simple schema checks only to optimize execution speed and lower system latency.

## Answers

- Recap 1: **C**: Tools like jq allow structured parsing of JSON traces to accurately filter specific fields and count error codes without manual searching. (W10.L1.C1)
- Recap 2: **B**: The workflow requires searching for signature patterns and collecting concrete log lines to validate failure hypotheses before altering the code context. (W10.L1.C2)
- Recap 3: **D**: Repeatedly executing identical commands without state progression indicates a logic loop, evidenced by repeating sequences in execution log traces. (W10.L1.C3)
- Quiz 1: **C**: AI models exhibit non-deterministic or probabilistic outputs, making precise expected-value assertions impossible and giving rise to the test oracle problem. (W10.L2.C1)
- Quiz 2: **A**: Metamorphic testing checks whether key relationships between inputs and outputs hold (such as rotational invariance) without needing an explicit ground-truth oracle for every input. (W10.L2.C2)
- Quiz 3: **B**: Contract testing and schema validation enforce explicitly agreed data structural formats between upstream data pipelines and downstream AI models, failing early on breaking schema changes. (W10.L2.C3)
- Quiz 4: **B**: Calibration measures how closely a model's predicted confidence probabilities reflect real-world outcomes (e.g., an output probability of 0.7 corresponds to a 70% actual frequency). (W10.L2.C4)
- Quiz 5: **D**: Latency measures time-to-response for inferences, making it the primary operational metric for strict real-time safety systems with tight SLA constraints. (W10.L2.C5)
- Quiz 6: **C**: High-risk AI architectures require multi-layered testing: metamorphic testing addresses the oracle problem for unit-level edge cases, while contract and drift monitoring safeguard pipeline integrity in production. (W10.L2.C6)
