# Review quiz · W11.L2 · Pipeline evaluation mechanisms and metrics

## Recap of the previous lecture (5 min)

1. You are auditing an AI-native recommendation API that currently relies only on static unit tests and offline Precision@K metrics. Your gap analysis reveals that the system frequently fails when real users request rare categories. Which improvement best addresses this evaluation gap?
   - A. Increase code coverage of the API route handlers to 100%.
   - B. Integrate behavioral test suites using edge-case inputs alongside online slice-based evaluation metrics.
   - C. Measure latency using load testing tools without changing model evaluation metrics.
   - D. Switch the recommendation algorithm database from PostgreSQL to Redis.

## Review quiz (10 min)

1. Why are traditional assertion-based unit tests insufficient for evaluating AI-native systems?
   - A. System-centric testing only measures underlying hardware usage rather than software behavior.
   - B. AI models do not use standard programming languages or software engineering pipelines.
   - C. AI-native systems exhibit nondeterminism and data drift, making fixed input-output assertions fragile.
   - D. Model training completely replaces all traditional software source code in production.

2. When testing an ML model function without ground-truth labels (the oracle problem), which mechanism verifies logic by checking if relations between transformed inputs and outputs hold?
   - A. Metamorphic testing
   - B. Pipeline replay
   - C. Schema validation
   - D. Static validation

3. Which integration testing technique ensures that data passing between components in an ML pipeline adheres to expected data types, values, and structural bounds?
   - A. Metamorphic testing
   - B. Schema validation
   - C. Perplexity scoring
   - D. Calibration error checking

4. A diagnostic AI outputs probability scores. Which metric measures how closely these predicted confidence probabilities reflect the true frequency of outcomes?
   - A. Throughput
   - B. Perplexity
   - C. Calibration error
   - D. F1 score

5. An online AI service must meet an SLA requirement of serving 100 requests per second with response times under 50ms. Which pair of system metrics monitors this?
   - A. Latency and Throughput
   - B. F1 score and Perplexity
   - C. AUC and Calibration Error
   - D. Data Freshness and Metamorphic Ratio

6. A team implements integration schema validation and model calibration checks for an NLP system. Which quality gap remains unaddressed by this evaluation setup?
   - A. Alignment of model confidence probabilities
   - B. Structural compliance of input payloads
   - C. Data type correctness between pipeline stages
   - D. Robustness against perturbed or adversarial inputs

7. A RAG pipeline shows good retrieval accuracy but slow overall response times. Which evaluation strategy best isolates whether the delay comes from the retrieval component or the generator model?
   - A. Compute overall corpus perplexity instead of F1 score.
   - B. Benchmark latency independently for vector retrieval versus LLM token generation.
   - C. Add schema validation to the generator output parser.
   - D. Apply metamorphic transformations to the vector database index.

## Answers

- Recap 1: **B**: Addressing coverage gaps in AI services requires behavioral testing targeted at edge cases and slice-based metrics to evaluate sub-population performance beyond aggregate precision. (W11.L1.C1)
- Quiz 1: **C**: AI-native systems introduce non-determinism, data drift, and model evolution, which makes fixed deterministic assertion testing inadequate. (W11.L2.C1)
- Quiz 2: **A**: Metamorphic testing addresses the test oracle problem by checking whether expected relations hold between outputs when specific transformations are applied to inputs. (W11.L2.C2)
- Quiz 3: **B**: Schema validation inspects pipeline data flow to guarantee that inputs and outputs meet structural contracts before execution reaches downstream models. (W11.L2.C3)
- Quiz 4: **C**: Calibration error evaluates whether a model's predicted confidence probabilities accurately match observed empirical frequencies. (W11.L2.C4)
- Quiz 5: **A**: Latency measures per-request response time while throughput tracks request handling capacity, directly mapping to production operational SLAs. (W11.L2.C5)
- Quiz 6: **D**: Schema checks cover pipeline integration and calibration checks cover model confidence, but neither tests model behavior against adversarial perturbations. (W11.L2.C6)
- Quiz 7: **D**: Separating system metrics (retrieval latency) from model generation latency isolates component-level performance bottlenecks in a multi-stage RAG architecture. (W11.L2.C7)
