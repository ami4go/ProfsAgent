## Review quiz (5 min)

1. In an automated AI-native software factory pipeline, what is the primary role of the model validation stage before deployment?
   - A. To convert raw unstructured data into standardized formats for ingestion
   - B. To re-train base models using real-time production feedback
   - C. To evaluate model performance and safety metrics against defined thresholds before release
   - D. To run stress tests on infrastructure hardware to check server latency under load

2. A team notices their deployed ML system's accuracy degrades over time despite passing all code unit tests and initial validation. Which automated testing stage should be added to catch this issue early?
   - A. Continuous data drift detection stage
   - B. Unit testing of feature engineering functions
   - C. Code syntax linting stage
   - D. Integration testing of data ingestion APIs

3. A team needs to satisfy a strict reproducibility requirement for a safety-critical AI system. How does this requirement alter pipeline test design compared to a system focused primarily on execution latency?
   - A. Reproducibility requires replacing integration tests with unit tests across all stages.
   - B. Reproducibility is tested exclusively in post-deployment monitoring, whereas latency is tested pre-training.
   - C. Reproducibility requires adding automated checks for data versioning, fixed seeds, and pipeline environment hashing.
   - D. Reproducibility mandates disabling automated data drift detection to keep training fixed.

4. An auditor reviews an AI deployment pipeline that runs unit tests and latency benchmarks, but lacks data drift monitoring and automated fairness checks. What is the correct assessment of this pipeline's reliability?
   - A. The pipeline is flawed because it fails to run manual regression tests prior to model training.
   - B. The pipeline is highly reliable because unit tests and latency checks ensure code correctness and responsiveness.
   - C. The pipeline is deficient because missing drift monitoring and fairness checks leave it vulnerable to silent failure and biased outputs in production.
   - D. The pipeline meets software factory standards as long as code coverage metrics exceed 90%.

## Answers

- Recap 1: **C**: AI-native systems introduce non-determinism, data drift, and model evolution, which makes fixed deterministic assertion testing inadequate. (W11.L2.C1)
- Recap 2: **A**: Metamorphic testing addresses the test oracle problem by checking whether expected relations hold between outputs when specific transformations are applied to inputs. (W11.L2.C2)
- Recap 3: **B**: Schema validation inspects pipeline data flow to guarantee that inputs and outputs meet structural contracts before execution reaches downstream models. (W11.L2.C3)
- Quiz 1: **C**: The model validation stage ensures that a newly trained model meets accuracy, fairness, and safety thresholds before it is automatically promoted to deployment. (W11.L3.C1)
- Quiz 2: **A**: Continuous data drift detection monitors live input data distributions against training distributions, identifying shifts that degrade model accuracy in production. (W11.L3.C2)
- Quiz 3: **C**: Mapping reproducibility to test design requires validating deterministic execution (seeds, data split versions, environment hashing), whereas latency requirements focus on timing and throughput checks under load. (W11.L3.C3)
- Quiz 4: **C**: Evaluating pipeline evidence shows that omitting continuous drift detection and fairness validation creates unmitigated risks of model decay and algorithmic bias in live environments. (W11.L3.C4)
