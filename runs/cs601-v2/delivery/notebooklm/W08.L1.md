## 2 · Course context (paste as a text source)

```text
COURSE: Software Development using AI (IIIT-Delhi, level 3xx, 3/4-year B.Tech students)
LECTURE: W08.L1 · week 8 · Iterative development and loop engineering (60 minutes)

LEARNING OUTCOMES (what students must be able to do):
- Trace execution logs produced by coding agents during iterative loop engineering tasks, recording all control-flow steps across the log artifact.

STUDENTS ALREADY KNOW:
- Iterative Loop Engineering Overview (earlier lecture on this topic)
- Execution Log Structure and Fields (earlier lecture on this topic)
- Control‑Flow Step Taxonomy (earlier lecture on this topic)
- Instrumentation and Logging Frameworks (earlier lecture on this topic)
- Worked Example: Simple Agent Loop Trace (earlier lecture on this topic)
- Activity: Instrument a Toy Agent (earlier lecture on this topic)
- Mapping Log Steps to Code Changes (earlier lecture on this topic)
- Pitfalls and Best Practices in Tracing (earlier lecture on this topic)

THIS LECTURE, PART BY PART:
1. Recap: Log Schema and Step Types (15 min, concept)
   Teaches: Students quickly review the log schema and control‑flow taxonomy from the previous session to reinforce shared vocabulary before advanced topics.
   Key terms: recap, log schema, step taxonomy, shared vocabulary, reinforcement
2. Advanced Tracing: Nested and Parallel Loops (15 min, mechanism)
   Teaches: Students examine how nested iterative loops and concurrent agent executions appear in a single log, learning to disambiguate interleaved control‑flow steps using correlation IDs.
   Key terms: nested loop, parallel execution, correlation ID, interleaved steps, disambiguation
3. Worked Example: Real‑World Agent Log Analysis (15 min, worked example)
   Teaches: Students walk through a full‑scale log from a production coding agent, extracting the generate‑test‑refactor cycles, identifying bottlenecks, and proposing instrumentation improvements.
   Key terms: production log, generate-test-refactor cycle, bottleneck detection, instrumentation improvement, log analysis
4. Activity: Group Log Trace Report (15 min, activity)
   Teaches: In teams, students receive an anonymized iterative development log, produce a structured trace report linking each control‑flow step to code artifacts, and present findings.
   Key terms: team analysis, anonymized log, trace report, code artifact linking, presentation

COMES LATER (do not teach here):
- Iterative development logs and software factory outputs (week 8)
```
