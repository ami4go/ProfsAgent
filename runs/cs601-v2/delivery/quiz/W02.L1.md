# Review quiz · W02.L1 · Model context protocols and architecture

## Review quiz (10 min)

1. How do resources differ from tools in Model Context Protocols (MCP)?
   - A. Resources allow models to execute shell commands, whereas tools only provide static files.
   - B. Resources provide passive context data for reading, whereas tools enable dynamic side-effects and execution.
   - C. Resources are defined on the host client, whereas tools reside exclusively on external cloud services.
   - D. Resources require dynamic parameters, whereas tools do not accept input arguments.

2. A developer wants to expose dynamic log streams where the log file URI changes based on a requested user ID parameter. Which MCP construct should they use?
   - A. A parameterized Resource Template with a dynamic URI scheme
   - B. A static tool definition with hardcoded execution parameters
   - C. An environment variable override in the host workspace setting
   - D. A fixed text resource without dynamic URI mapping

3. How does an MCP host validate arguments provided by an LLM before invoking a tool via `tools/call`?
   - A. It validates arguments against the `inputSchema` declared in the server's `tools/list` response.
   - B. It converts all input values to strings automatically without schema checks.
   - C. It forwards the raw prompt to a manual host validation queue.
   - D. It relies on the server to bypass validation if the connection uses stdio.

4. Which mandatory fields are required in an `mcpServers` workspace configuration entry to launch a local subprocess context server?
   - A. `command` and `args` to specify the executable binary and its launch arguments
   - B. `uriTemplate` and `mimeType` to specify context encoding formats
   - C. `promptInjection` and `sandboxMode` to set protocol execution boundaries
   - D. `toolsList` and `callResult` to map server callback functions

5. An external tool returns raw text output that contains malicious instructions designed to hijack the LLM context. What is the most effective mitigation strategy?
   - A. Enforcing user-in-the-loop explicit approvals before executing sensitive downstream tools
   - B. Running the server in high-privilege administrator mode to override unexpected errors
   - C. Disabling all logging from stderr to suppress error messages
   - D. Hardcoding database secrets directly inside the shared client configuration file

6. A student configures an MCP server in `mcpServers` with `"command": "python"`, but the server immediately terminates because it lacks the script path and API key. Which part of the configuration template needs fixing?
   - A. Adding the script path under `args` and the required API key key-values under `env`
   - B. Changing the server protocol registration from JSON-RPC to XML
   - C. Removing the `command` attribute and replacing it with a static `uri` scheme
   - D. Updating the tool's JSON Schema type definitions from string to boolean

7. A local MCP server process fails during initialization without sending a JSON-RPC error response. Where should a developer look to diagnose the startup error?
   - A. The subprocess `stderr` log stream of the context server
   - B. The server's public `resources/list` payload
   - C. The client host's static UI rendering logs
   - D. The `inputSchema` section of the prompt catalog

## Answers

- Quiz 1: **B**: Resources act as passive data providers (like context or read-only files), while tools allow models to run dynamic operations and side-effects. (W02.L1.C1)
- Quiz 2: **A**: Resource templates expose parameterized URI schemes, allowing clients to construct dynamic URIs to read specific dynamic context. (W02.L1.C2)
- Quiz 3: **A**: Tools define their input requirements via standard JSON Schema (`inputSchema`) during discovery (`tools/list`), which allows strict client/server argument validation. (W02.L1.C3)
- Quiz 4: **A**: Subprocess server declarations in `mcpServers` require at minimum the executable `command` and optional command-line `args` (along with `env`) to start the server. (W02.L1.C4)
- Quiz 5: **A**: Requiring explicit human approval (user-in-the-loop) for sensitive side-effects stops prompt injections contained in untrusted tool responses from executing unchecked actions. (W02.L1.C5)
- Quiz 6: **A**: Command-line arguments (like script files) must be passed via the `args` array and environment parameters (like API keys) must be set in the `env` dictionary of the configuration schema. (W02.L1.C6)
- Quiz 7: **A**: Runtime crashes, missing dependencies, or syntax errors in local server binaries output details directly to the subprocess standard error (`stderr`) stream. (W02.L1.C7)
